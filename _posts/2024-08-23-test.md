This blog post summarizes our paper, [**FAHNES: Feature-Aware Hypergraph Generation via Next-Scale Prediction**](), which builds on our prior work, [**HYGENE: A Diffusion-based Hypergraph Generation Method**](https://doriangailhard.github.io/blog/2024/HYGENE/).

**TL;DR:** We introduce a framework that generates hypergraphs with node and hyperedge features, based on an "unzoom–zoom" principle. First, the input hypergraph is coarsened into increasingly simplified representations ("unzoom") by merging nodes and hyperedges. We track how many nodes each cluster represents and average features accordingly. Then, we train a model to reconstruct fine-grained structure from these coarse versions ("zoom"). Generation is performed by repeatedly applying the model to zoom in and increase detail until a full hypergraph is synthesized.

[Traditional graphs](https://en.wikipedia.org/wiki/Graph) consist of nodes connected by edges, each linking exactly two nodes. [Hypergraphs](https://en.wikipedia.org/wiki/Hypergraph), by contrast, allow hyperedges to connect any number of nodes, capturing higher-order relationships. This makes hypergraphs especially expressive in domains such as:

- 3D meshes, where faces can be represented as 3-edges
- Electronic circuits, with routers modeled as hyperedges connecting all components
- Molecular structures, where functional groups (e.g., carboxylic acids) can form hyperedges

Our aim is to build a deep learning method that can generate new samples from distributions of featured hypergraphs — for example, to synthesize new 3D shapes resembling input mesh variants. While [**HYGENE**](https://doriangailhard.github.io/blog/2024/HYGENE/) addressed topology generation, **FAHNES** extends this by improving structural quality and supporting features.

### HYGENE: A Diffusion-based Hypergraph Generation Method

Our approach builds on [**HYGENE**](https://doriangailhard.github.io/blog/2024/HYGENE/), which introduced a multi-scale "unzoom–zoom" scheme:

#### 1. Hypergraph Downsampling (Unzoom)

We coarsen the hypergraph using two graph projections:

- **Clique Expansion**: Replaces each hyperedge with a weighted clique, preserving spectral properties and allowing graph coarsening.
- **Star Expansion (Bipartite View)**: Represents the hypergraph as a bipartite graph with nodes on one side and hyperedges on the other.

We apply a **spectral-preserving coarsening** algorithm on the clique expansion, and mirror the same merges in the bipartite view. Hyperedges are merged when their node sets become identical.

#### 2. Hypergraph Upsampling (Zoom)

We train a model to reverse the coarsening process:

- **Expansion**: Predicts new nodes/hyperedges from coarse ones, maintaining connections.
- **Refinement**: Filters edges to enforce structural consistency.

At generation time, we start from a minimal graph and expand it iteratively.

## Our Work

**FlowAR** excels at generating features but lacks topology modeling. **HYGENE**, conversely, generates topology but not features. Our method bridges this gap by adding support for **node budgets**, feature-aware hierarchical generation, and refinement.

### Coarsening Sequence / Downsampling

Each node and hyperedge initially has a node budget of one. As nodes are merged during coarsening, the resulting cluster’s budget becomes the sum of its components. Features are averaged using budget-weighted means. Thus, each cluster encodes the average feature of the nodes it represents.

During generation, child nodes/hyperedges inherit the coarse feature and are refined by the model to predict their finer features.

### Coarsening Inversion / Upsampling

Instead of directly predicting child node budgets, the model learns **splitting ratios** — i.e., what fraction of the parent’s budget each child receives. This constrains outputs to [0, 1] and improves training stability. Inputs are encoded with sinusoidal positional embeddings to reduce variance.

For features, the coarse feature is first duplicated across children (like a pixelated image), and the model refines it — similar to FlowAR’s coarse-to-fine enhancement.

**Limitations**

In molecule generation, our model is outperformed by one-shot predictors. We hypothesize this is due to the **discrete nature** of our generation process. In image generation, small errors yield small differences — nearby pixels stay close in latent space. But in hypergraph generation, small prediction errors (e.g., adding/removing an edge) can alter topology drastically, changing the message-passing structure and disrupting embeddings. One-shot models are more robust because they operate on fixed connectivity.

---

## Conclusion

This work is a step toward hierarchical, feature-aware hypergraph generation. Future work will aim to improve robustness to prediction errors and better model discrete structure.
