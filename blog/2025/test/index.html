FAHNES: Feature-Aware Hypergraph Generation via Next-Scale Prediction

Created in June 02, 2025

2025   ·   machine-learning   generative-models   graph-theory   hypergraphs   ·   papers

This blog post summarizes our recent paper, FAHNES: Feature-Aware Hypergraph Generation via Next-Scale Prediction, which builds upon our prior work, HYGENE: A Diffusion-based Hypergraph Generation Method.

TL;DR: FAHNES introduces a framework to generate hypergraphs with both topology and features using an “unzoom-zoom” principle. Starting from a coarse, abstracted version of a hypergraph, our model learns to progressively reconstruct the original structure and features through a series of upsampling steps. This enables generation of realistic, detailed featured hypergraphs from scratch.

Why Hypergraphs?

A random graph and a random hypergraph.

Unlike traditional graphs—where edges connect exactly two nodes—hypergraphs allow hyperedges that connect any number of nodes. This makes them especially useful for capturing higher-order relationships in data:

  • 3D meshes: Triangles become 3-edges.
  • Electronic circuits: Routers connect multiple components simultaneously.
  • Molecules: Functional groups like carboxylic acids can be treated as unified substructures.

Our goal: learn to generate new samples from distributions of featured hypergraphs. For instance, given a set of 3D meshes or molecular structures, the model should be able to generate realistic variants, including both their topology and their node/edge attributes.

From HYGENE to FAHNES

In HYGENE, we introduced a diffusion-based approach to generate topology using a hierarchical “unzoom-zoom” framework.

FAHNES extends this to featured hypergraphs: in addition to structural generation, we now generate node and hyperedge features with higher fidelity.

We take inspiration from hierarchical image generation (like FlowAR), which first generates coarse versions and then progressively refines details.

Core Ideas

Inspirations

FlowAR: Hierarchical Image Generation with Flow Matching

FlowAR starts from a low-resolution image and gradually upsamples it. At each step, it denoises random noise conditioned on the previous (coarser) prediction, similar to how we zoom in during hypergraph generation.

HYGENE: Unzoom–Zoom for Hypergraph Topology

We reuse HYGENE’s two-stage approach:

  • Downsampling (“Unzoom”): Coarsen the input hypergraph using clique and bipartite projections.
  • Upsampling (“Zoom”): Reconstruct finer-scale topology from the coarser level using a learned model.
Clique and bipartite projections enable spectral-preserving coarsening. This gives us multiscale representations we can use for training a generative model.

What’s New in FAHNES

While HYGENE can generate topology, it lacks support for features. FlowAR handles features but doesn’t generate topology. FAHNES brings both together.

1. Node Budgets

Each node/hyperedge is assigned a budget indicating how many original elements it represents. During coarsening, these budgets are summed; during upsampling, they are split among new nodes/hyperedges.

Instead of predicting absolute budget values, the model predicts splitting ratios, bounded between 0 and 1—making training more stable and accurate.

Features are averaged during coarsening, weighted by node budgets. During generation, coarse features are passed down and refined by the model.

Examples of multiscale coarsening applied to meshes.

2. Feature Refinement

Feature refinement is inspired by hierarchical image generation:

  1. Children inherit their parent’s (averaged) features.
  2. A neural model predicts refined features based on these coarse values and local topology.

We use sinusoidal encodings for input budgets to reduce training variance and encourage smooth generalization.

Full FAHNES pipeline: coarsen, learn to invert the process (splits + edges + features), and expand iteratively from the root.

Results & Limitations

⚠️ Limitations

In molecular tasks, FAHNES is currently less competitive than one-shot models. We believe this is due to the discrete decision bottleneck in hierarchical generation:

  • In images, small errors create small deviations.
  • In hypergraphs, a minor mistake can drastically change the topology due to thresholding (e.g. adding/removing an edge).

One-shot models avoid this problem by generating over a fixed topology, which makes them more robust in such settings.

Conclusion

FAHNES takes a key step toward hierarchical generation of featured hypergraphs, combining insights from both image and graph domains. While early results are promising, improving robustness to discrete decision errors will be central to future work.
